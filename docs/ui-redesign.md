# UI/UX redesign

## Реалізація

- Єдина система кольорів, типографіки, відступів, карток, форм і станів взаємодії: `src/styles/theme.ts`, `global.css`, `auth.css`, `pages.css`.
- Оновлені всі сторінки: початкова, вхід, реєстрація, підтвердження пошти, визначення тональності, камертон, шаблони та профіль.
- Спільні `Brand`, `PageHeading`, Header, Footer, налаштування, повідомлення та індикатор очікування. Нових залежностей немає.
- При ширині від 1100 px і висоті від 600 px використовується бічна навігація. На менших або нижчих вікнах — постійно доступна нижня навігація із зарезервованим місцем у контенті та підтримкою safe area.
- Сітки, короткі альбомні вікна, контейнерні запити для шаблонів, перенесення довгого тексту та діалоги з обмеженням за висотою viewport.
- Видимий клавіатурний фокус, посилання пропуску навігації, підписані контролери, стани очікування та підтримка reduced motion. Основний і другорядний текст перевірені на контраст; межі полів мають контраст понад 3:1.
- Англійська залишається початковою мовою; доступні також українська та німецька. Для нового користувача використовується світла тема, збережені налаштування теми зберігаються.
- Збережені Firebase, маршрути, перевірка пошти, визначення тональностей, реальні аудіофайли та шаблони. Виправлені скасування повільного запуску аудіо й збереження правильного індикатора відтворення після невдалого видалення.
- PWA зберігає standalone, автоматичне оновлення та precache. Збірка розділяє React, MUI і Firebase на стабільні файли для повторного використання кешу; найбільший JS-файл — приблизно 453 kB, основний код застосунку — 68 kB до gzip. Загальний початковий розмір завантаження не вимірювався як окремий performance benchmark.

## Технічні перевірки

- 24 автоматизовані регресійні тести: відомі мажорні/мінорні тональності та аудіовідповідності, перевірка параметрів, збереження шаблону, форми й переходи авторизації, очікування та скасування аудіо, успішне й невдале видалення.
- Команда тестів: `npm.cmd test -- --configLoader native --pool=threads`.
- `npm.cmd run build` проходить разом із суворою перевіркою TypeScript. Увімкнені `noUnusedLocals` і `noUnusedParameters`.
- Prettier та `git diff --check`. Окремого налаштованого linter у проєкті немає.
- Production-збірка генерує manifest, service worker та precache для 38 файлів.
- Production-preview перевірено окремо: чотири публічні екрани, зміна теми, активація service worker та перезавантаження кешованого `/auth` без мережі.

## Браузерна перевірка

Реальні компоненти й маршрути відрендерено в ізольованому Chrome через DevTools Protocol. Для захищених сторінок використовувався локальний стан Redux; production-запити Firebase були заблоковані. Для всіх розмірів перевірено горизонтальне переповнення й доступність контролерів після прокручування; репрезентативні скриншоти додатково переглянуто візуально.

| Група                    | Розміри, CSS px                            |
| ------------------------ | ------------------------------------------ |
| Телефони, портрет        | 320×568, 360×640, 390×844, 430×932         |
| Телефони, альбом         | 568×320, 667×375, 844×390, 932×430         |
| Планшети, портрет        | 768×1024, 820×1180                         |
| Планшети, альбом         | 1024×768, 1180×820                         |
| Ноутбуки                 | 1280×720, 1366×768                         |
| Великі екрани            | 1920×1080, 2560×1440, 3440×1440, 3840×2160 |
| Проміжні та низькі вікна | 540×720, 1024×420                          |

Перевірено всі вісім основних екранів, світлу й темну теми, три мови, довгі назви та адреси, порожні шаблони, діалог видалення й скасування, блокування навігації під час запитів, введення у форми, клавіатуру, сенсорну емуляцію, pixel density, зміну розміру вікна та емуляцію збільшення тексту до 200%. Окремо перевірено реальне відтворення MP3 й скасування запиту, затриманого на рівні браузера.

Скриншоти й докладні JSON-звіти поточного сеансу збережені поза репозиторієм у `%TEMP%/tonality-ui-review`.

## Межі перевірки

Фізичні iOS/Android-пристрої, Safari/Firefox, реальна екранна клавіатура, screen reader і встановлення PWA через системне меню не перевірялися. Збільшення тексту й touch перевірялися через емуляцію, а не як фізичні налаштування пристрою. Реєстрація production-акаунта, фактична доставка email та запис у production Firestore не виконувалися; відповідні UI-переходи й помилки перевірені ізольовано.
